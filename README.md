# 마편런 (가칭)

> 군대 내 부조리를 피해 증거를 모으고, 마음의 편지를 작성해 제출하는 짧은 2D 스텔스 웹 게임.

## 프로젝트 상태

현재 단계는 **기획 및 기술 설계**입니다. 아직 구현은 시작하지 않았습니다.

이 저장소에서는 먼저 게임의 핵심 재미, MVP 범위, 기술 구조, 콘텐츠 원칙을 문서로 확정한 뒤 구현에 들어갑니다.

## 핵심 컨셉

플레이어는 부대 내부를 돌아다니며 부조리와 관련된 증거를 수집합니다. 선임 NPC의 순찰과 감시를 피해야 하며, 필요한 증거를 모두 모으면 마음의 편지를 작성할 수 있습니다. 편지를 완성한 뒤 마음의 편지함까지 무사히 도달해 제출하면 클리어됩니다.

게임의 핵심 경험은 다음과 같습니다.

- 선임에게 발각될지 모르는 스텔스 긴장감
- 군대식 부조리를 과장한 풍자와 코미디
- 마음의 편지를 제출했을 때의 해방감

## 목표 플랫폼

- 웹 브라우저
- 별도 설치 없이 URL 접속 후 즉시 플레이
- PC 우선 지원
- 향후 모바일 브라우저 지원 고려
- 로그인 없이 플레이 가능

## 초기 기술 방향

현재 기준으로 다음 조합을 우선 검토합니다.

- TypeScript
- Phaser 3
- Vite
- Tiled Map Editor
- Phaser Arcade Physics
- 정적 웹 배포 (Cloudflare Pages / Vercel / GitHub Pages)

최종 기술 선택은 Vertical Slice 프로토타입에서 조작감과 스텔스 시스템을 검증한 뒤 확정합니다.

## MVP 한 줄 정의

> 하나의 작은 맵에서 선임 한 명의 시야와 추적을 피해 증거 3개를 모으고, 마음의 편지를 작성해 편지함에 제출하는 5~10분짜리 웹 게임.

## 현재 우선순위

1. 게임 디자인과 핵심 플레이 루프 확정
2. MVP 범위 고정
3. 기술 구조와 AI 설계 확정
4. Vertical Slice 구현
5. 플레이 테스트 및 밸런싱
6. 아트/사운드 적용
7. 웹 배포

## 주의

본 프로젝트는 군대 내 부조리를 소재로 한 풍자 게임을 목표로 합니다. 실존 인물이나 특정 개인을 직접 묘사하거나 비방하는 방향은 피하고, 캐릭터와 사건은 게임을 위해 허구화하는 것을 기본 원칙으로 합니다.
