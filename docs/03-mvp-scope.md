# MVP 범위 정의

## 1. 목적

MVP의 목표는 기능을 많이 넣는 것이 아니라, **핵심 스텔스 루프가 실제로 재미있는지 검증 가능한 하나의 완성된 플레이 경험**을 만드는 것이다.

MVP는 한 판 약 5~10분을 목표로 한다.

---

## 2. MVP 한 줄 정의

> 하나의 작은 맵에서 선임 한 명의 시야와 추적을 피해 증거 3개를 모으고, 마음의 편지를 작성해 편지함에 제출하는 웹 게임.

---

## 3. 반드시 포함할 기능

### 기본 흐름

- 타이틀 화면
- 게임 시작
- 게임 플레이
- 성공 엔딩
- 실패 엔딩

- 상호작용
- 멘탈
- 피격 후 짧은 보호 시간

### 맵

- 단일 맵
- 생활관/복도/작은 방 몇 개 수준의 구조
- 벽과 장애물
- 플레이어 시작 위치
- 선임 시작 위치
- 순찰 포인트
- 증거 위치 3곳
- 편지 작성 위치
- 편지함

### 선임 AI

- Patrol
- Player detection
- Chase
- Capture
- Patrol 복귀

### 탐지

- 거리
- 시야각
- 벽 차폐
- 짧은 탐지 지연

### 증거

- 총 3개
- 상호작용으로 획득
- 중복 획득 방지
- HUD 진행도 반영

### 마음의 편지

- 증거 3개 수집 후 작성 가능
- 작성 중 이동 불가
- 작성 Progress 표시
- 작성 중 발각 가능
- 완료 시 최종 목표 전환

### 편지함

- 편지 작성 완료 후 제출 가능
- 제출 시 성공 엔딩

### UI

- Mental
- Evidence count
- Current objective
- Interaction prompt
- Ending result

### Audio

최소한 다음 이벤트에 피드백을 제공한다.

- 탐지
- 피격
- 증거 획득
- 편지 완료
- 성공

## 4. MVP에서 의도적으로 제외하는 기능

다음 기능은 아이디어가 좋아도 초기 버전에 넣지 않는다.

### 온라인 기능

- 로그인
- 회원가입
- 백엔드 API
- 온라인 랭킹
- 멀티플레이
- 클라우드 저장

### 콘텐츠 확장

- 여러 스테이지
- 여러 선임 NPC
- 복잡한 NPC 관계
- 여러 종류의 아이템
- 복잡한 인벤토리
- 절차적 맵 생성
- 긴 스토리 모드
- 다수의 미니게임

### 플랫폼

- 네이티브 모바일 앱
- 모바일 전용 UX 완성
- 게임패드 완전 지원

### 부가 시스템

- 업적
- 계정 기반 통계
- 리플레이
- 커스텀 맵
- UGC
- 서버 검증 기록

## 5. MVP 플레이 흐름

```text
START
  ↓
짧은 조작 안내
  ↓
맵 탐색
  ↓
증거 1/3
  ↓
선임 회피 / 추적
  ↓
증거 2/3
  ↓
증거 3/3
  ↓
마음의 편지 작성
  ↓
최종 러시
  ↓
편지함 제출
  ↓
CLEAR
```

실패 흐름:

```text
선임에게 반복적으로 잡힘
  ↓
MENTAL 0
  ↓
GAME OVER
  ↓
RETRY
```

## 6. 목표 플레이 시간

| 구간 | 목표 시간 |
| --- | ---: |
| 조작 적응 | 10~30초 |
| 증거 탐색 | 2~4분 |
| 스텔스/추격 | 전체 플레이에 자연스럽게 포함 |
| 편지 작성 | 약 5초 |
| 최종 러시 | 20~40초 |
| 전체 | 약 5~10분 |

---

## 7. 난이도 목표

첫 플레이 기준 클리어 확률을 대략 **50~70%** 범위에서 시작해 테스트한다.

목표는 높은 난이도가 아니라 다음 경험이다.

- 처음에는 긴장됨
- 한두 번 잡힐 수 있음
- 규칙을 이해하면 클리어 가능
- 실패 후 바로 재도전하고 싶음

---

## 8. Vertical Slice 범위

MVP 전체보다 먼저 아래 최소 프로토타입을 만든다.

```text
Player
+ Senior
+ 몇 개의 벽
+ Patrol
+ Vision
+ Chase
+ Capture
```

아직 증거, 마음의 편지, 엔딩은 넣지 않는다.

### Vertical Slice 성공 기준

플레이 테스트에서 다음 질문에 긍정적으로 답할 수 있어야 한다.

- 선임을 피해서 이동하는 것이 긴장되는가?
- 시야 규칙을 플레이어가 이해할 수 있는가?
- 발각되었을 때 도망칠 여지가 있는가?
- 추격이 불공정하게 느껴지지 않는가?
- 다시 시도하고 싶은가?

실패하면 콘텐츠를 추가하지 않고 다음을 먼저 수정한다.

- 맵 구조
- 이동 속도
- 선임 속도
- 시야각
- 시야 거리
- 탐지 지연
- 사운드 피드백

## 9. Definition of Done

다음 조건을 모두 만족하면 MVP 완료로 본다.

### 기능

- URL 접속으로 실행 가능
- 플레이어 이동 정상
- 벽 충돌 정상
- 선임 순찰 정상
- 선임 탐지 정상
- 추적 정상
- 잡히면 멘탈 감소
- 멘탈 0이면 Game Over
- 증거 3개 획득 가능
- 증거 완료 전 편지 작성 불가
- 편지 작성 정상
- 작성 중 발각 가능
- 작성 완료 전 편지 제출 불가
- 편지함 제출 시 Clear
- Ending 화면 정상
- Retry 정상

### 품질

- 일반적인 최신 PC 브라우저에서 플레이 가능
- 치명적인 soft-lock 없음
- 플레이 진행 불가능한 맵 배치 없음
- 목표가 HUD에서 항상 확인 가능
- 왜 발각됐는지 대체로 이해 가능
- 첫 플레이가 10분을 크게 넘지 않음

### 배포

- production build 성공
- 정적 호스팅에서 실행 성공
- 공유 가능한 public URL 존재

---

## 10. MVP 이후 우선 후보

MVP가 재미있다는 판단이 나온 뒤에만 확장한다.

우선순위 후보:

1. 다양한 부조리 이벤트
2. 의심도 시스템
3. 추가 선임 AI 유형
4. 랜덤 이벤트
5. 여러 엔딩
6. 모바일 조작
7. 결과 공유 카드
8. 타임 기록 / 랭킹

기준은 단순하다.

> 핵심 루프를 강화하지 않는 기능은 뒤로 미룬다.
